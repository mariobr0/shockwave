# Полное руководство по развертыванию Shockwave (Глобальный голосовой ввод)

Shockwave — это кастомный Python-скрипт, который позволяет вам надиктовывать текст в любом приложении Windows с помощью глобального хоткея. Он записывает звук, переводит его в текст локально (через Whisper) и отправляет в LLM (нейросеть) для исправления знаков препинания и ошибок, после чего копирует идеальный текст в буфер обмена.

Поскольку проект опирается на локальные технологии, для его работы требуется установить несколько сторонних утилит.

---

## Часть 1. Установка системных зависимостей

### 1. Установка SoX (Sound eXchange)
SoX — это консольная утилита для записи звука с микрофона.
1. Скачайте установщик для Windows (версия 14.4.2): [sox-14.4.2-win32.exe](https://sourceforge.net/projects/sox/files/sox/14.4.2/sox-14.4.2-win32.exe/download)
2. Установите программу. По умолчанию она установится в папку `C:\Program Files (x86)\sox-14-4-2`.
3. **КРИТИЧЕСКИ ВАЖНО ДЛЯ WINDOWS:** В Windows 11 SoX по умолчанию не видит микрофон. Откройте PowerShell и выполните команду для добавления системной переменной:
   ```powershell
   [Environment]::SetEnvironmentVariable("AUDIODRIVER", "waveaudio", "User")
   ```

### 2. Установка Whisper.cpp (Локальное распознавание речи)
Whisper.cpp — это сверхбыстрая версия модели Whisper от OpenAI, работающая на процессоре или видеокарте.
1. Перейдите на страницу релизов [whisper.cpp на GitHub](https://github.com/ggerganov/whisper.cpp/releases).
2. Скачайте архив под вашу систему (например, `whisper-bin-x64.zip` для обычных ПК или `whisper-cublas-...-bin-x64.zip`, если у вас видеокарта NVIDIA).
3. Распакуйте архив в любую удобную папку (например, `C:\tools\whisper`). Внутри вы найдете исполняемый файл (он может называться `whisper-cli.exe` или `main.exe`).
4. **Загрузка языковой модели:**
   Скачайте файл модели, например, [ggml-large-v3-turbo-q5_0.bin](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin). 
   Поместите его в удобную папку, например: `C:\Users\%USERNAME%\.local\share\whisper-cpp\`.

### 3. Настройка локальной или облачной LLM
Скрипту нужен OpenAI-совместимый API-сервер для "нормализации" текста (расстановки запятых). 
Это может быть:
* Ваш собственный локальный прокси, оборачивающий API Gemini (например, висящий на `http://127.0.0.1:8045/v1`).
* Локальный сервер LM Studio или Ollama.
* Напрямую API OpenAI (тогда endpoint будет `https://api.openai.com/v1/chat/completions`).

## Часть 2. Развертывание проекта Shockwave

### 1. Подготовка Python
Убедитесь, что у вас установлен Python (версии 3.10 или выше).

### 2. Загрузка и настройка скрипта
1. Склонируйте или скачайте папку с проектом `Shockwave`.
2. Откройте терминал в папке проекта и создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```
3. Установите необходимые библиотеки (`keyboard`, `requests`, `pyperclip`, `python-dotenv`):
   ```bash
   venv\Scripts\pip install -r requirements.txt
   ```

### 3. Настройка файла .env
Скопируйте файл `.env.example` и назовите его `.env`. Откройте его в текстовом редакторе и укажите правильные пути:

```env
# Пути к утилитам на вашем ПК
SOX_PATH=C:\Program Files (x86)\sox-14-4-2\sox.exe
WHISPER_PATH=C:\tools\whisper\whisper-cli.exe
MODEL_PATH=C:\Users\ВАШ_ЮЗЕР\.local\share\whisper-cpp\ggml-large-v3-turbo-q5_0.bin

# Настройки LLM
LLM_ENDPOINT=http://127.0.0.1:8045/v1/chat/completions
LLM_API_KEY=ваш_секретный_ключ
LLM_MODEL=gemini-3.1-flash-lite

# Настройки интерфейса
HOTKEY=f12
UI_POSITION=bottom-left
```

## Часть 3. Использование

1. Запустите скрипт двойным кликом по файлу `start.bat`. Откроется окно консоли, где будут отображаться полезные логи работы. Окно можно просто свернуть.
2. В левом нижнем углу экрана появится постоянная плашка с надписью **"what is your command?"**. Это значит, что скрипт готов. Вы можете включить или отключить чекбокс **"LLM norm"**, чтобы активировать или отключить ИИ-нормализацию текста.
3. Нажмите **F12** (или ваш хоткей), находясь **абсолютно где угодно** — не обязательно держать курсор в текстовом поле. Плашка сменит статус на **"🔴 record"**.
4. Произнесите нужный текст в микрофон.
5. Снова нажмите **F12**. Плашка последовательно покажет статусы **"⚙️ processing"** и **"🧠 normalization"**.
6. Как только появится надпись **"✅ ready"**, готовый идеальный текст ляжет в ваш буфер обмена. Нажмите `Ctrl+V` в любом удобном месте.
7. Через 5 секунд плашка вернется в дежурное состояние **"what is your command?"**, ожидая вашей следующей команды.

> 💡 **Полезный совет:** Консоль служит отличным журналом-бэкапом. Если вы случайно скопировали другой текст и затерли буфер обмена до того, как вставили диктовку, просто разверните окно консоли — ваш текст бережно сохранен в истории логов!
