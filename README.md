# Shockwave 🤖🎤

**Shockwave** — это умный инструмент для глобального голосового ввода на Windows, работающий в фоновом режиме. Он позволяет вам надиктовывать текст в любом приложении по нажатию глобального хоткея, а затем автоматически исправляет пунктуацию, очищает речь от слов-паразитов с помощью LLM и моментально вставляет готовый текст туда, где стоит ваш курсор.

Отличная локальная Windows-альтернатива таким инструментам, как FluidVoice.

## ✨ Особенности
* **Глобальный хоткей:** По умолчанию `F12`. Работает везде — в редакторах кода, браузере, мессенджерах.
* **Локальное распознавание (STT):** Использует `whisper.cpp` для быстрой и приватной транскрибации аудио.
* **Умная нормализация:** Любая LLM (например, Gemini или локальная модель) аккуратно исправляет опечатки, расставляет знаки препинания и капитализирует IT-термины (Docker, JSON, Git), не сокращая вашу оригинальную мысль.
* **Интерактивный UI:** Аккуратная, плавающая полупрозрачная плашка с чекбоксом для быстрого включения/отключения LLM на лету. Имеет кинематографичную анимацию растворения.
* **Универсальная вставка:** Текст надежно копируется в буфер обмена.

## 🛠️ Требования
* ОС Windows (10/11)
* Python 3.10+
* Установленный [SoX (Sound eXchange)](https://sourceforge.net/projects/sox/) для захвата микрофона.
* Скачанный [whisper.cpp](https://github.com/ggerganov/whisper.cpp) (`whisper-cli.exe`) и языковая модель (например, `ggml-large-v3-turbo-q5_0.bin`).
* Локальный или удаленный сервер LLM с OpenAI-совместимым API (по умолчанию порт 8045).

## 🚀 Установка
1. Клонируйте этот репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/Shockwave.git
   cd Shockwave
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   venv\Scripts\pip install -r requirements.txt
   ```
3. Скопируйте файл конфигурации:
   ```bash
   copy .env.example .env
   ```
4. Откройте `.env` и укажите свои пути к SoX, Whisper, модели, а также свой API-ключ.

## 🎧 Использование
Запустите файл `start.bat`. 

Откроется окно консоли (терминал), в котором будут отображаться логи работы (как Whisper распознает текст, что отправляется в LLM и т.д.). Консоль можно свернуть, чтобы она не мешала.
1. Установите курсор в любое текстовое поле.
2. Нажмите `F12` (появится плашка "🔴 Идет запись...").
3. Продиктуйте текст.
4. Снова нажмите `F12`.
Скрипт переведет голос в текст, отправит его на проверку грамматики и сохранит готовый результат в ваш буфер обмена.
