# Shockwave Setup Guide (Русский)

Это руководство поможет вам установить и настроить Shockwave на вашем ПК (Windows 10/11). 
Скрипт полностью автономен, написан на Python и автоматически скачивает все нужные модели.

## Шаг 1: Установка Python
Убедитесь, что у вас установлен Python (рекомендуется версия 3.10 или новее).
При установке **обязательно** поставьте галочку **"Add Python to PATH"**.

## Шаг 2: Установка зависимостей
Откройте командную строку в папке проекта и выполните установку библиотек:
```cmd
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Шаг 3: Настройка .env файла
Переименуйте файл `.env.example` в `.env` (или создайте новый) и настройте его:

```ini
# Настройки движка распознавания
STT_ENGINE=whisper
WHISPER_MODEL=large-v3-turbo

# Настройки нормализации (LLM)
LLM_ENDPOINT=http://127.0.0.1:8045/v1/chat/completions
LLM_API_KEY=your_api_key_here
LLM_MODEL=gemini-3.1-flash-lite

# Настройки интерфейса
HOTKEY=f12
UI_POSITION=bottom-left
```

### Выбор движка (STT_ENGINE)
Вы можете выбрать один из двух движков:
1. `STT_ENGINE=whisper` (Рекомендуется для разработчиков). Отлично понимает смешанную речь (русский + английский). Названия библиотек (Docker, Python, useEffect) пишет по-английски.
2. `STT_ENGINE=gigaam` (Для чистого русского текста). Работает в несколько раз быстрее, но все английские слова пишет кириллицей.

**Модели скачиваются автоматически!**
При первом запуске выбранная модель будет скачана из интернета (около 200-800 МБ) в системный кэш. Последующие запуски будут моментальными.

Если вы хотите указать путь к скачанным локально моделям, добавьте в `.env`:
`WHISPER_MODEL_PATH=C:\path\to\model` или `GIGAAM_MODEL_PATH=C:\path\to\model`.

## Шаг 4: Запуск
Запустите скрипт через `start.bat`.
В левом нижнем углу появится плавающий виджет с надписью `what is your command?`.

## Использование
1. Нажмите и **удерживайте** `F12` (или заданную кнопку), пока диктуете. Виджет покажет `record`.
2. Отпустите `F12`. Появится статус `processing` (распознавание аудио).
3. Если стоит галочка ИИ-коррекции, начнется `normalization` (исправление ошибок нейросетью).
4. Текст будет скопирован в буфер обмена, виджет покажет `ready`. Вы можете вставить текст (`Ctrl+V`) куда угодно.
