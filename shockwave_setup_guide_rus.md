# Shockwave — Руководство по настройке

Программа поддерживает два варианта установки: **Простая** (для обычных пользователей) и **Продвинутая** (для разработчиков, желающих работать с исходным кодом).

---

## Вариант 1. Простая установка (Готовый EXE)

Это самый быстрый способ запустить Shockwave без установки Python и сторонних библиотек.

### Шаг 1: Скачивание
1. Загрузите файл `Shockwave.exe` (находится в папке `dist`, если вы собирали проект сами, либо в релизах GitHub).
2. Поместите его в любую удобную для вас папку.

### Шаг 2: Настройка API ключа (.env)
Рядом с файлом `Shockwave.exe` создайте текстовый файл с именем `.env` (обратите внимание на точку в начале) и добавьте в него ваш API-ключ для LLM (например, Gemini):

```env
LLM_API_KEY=ваш_ключ_здесь
STT_ENGINE=gigaam
```

*Допустимые значения для `STT_ENGINE`: `whisper` или `gigaam`.*

### Шаг 3: Запуск
Дважды кликните по `Shockwave.exe`.
1. При первом запуске откроется **Панель управления (Launcher)** в консоли.
2. Программа автоматически скачает нужную нейросеть для распознавания голоса (Whisper или GigaAM) в ваш системный кэш. (Внимание: первая загрузка может занять время и потребовать до 2-3 ГБ свободного места).
3. Выберите пункт "Запустить Shockwave" в меню.
4. Дождитесь появления черной плашки виджета.
5. Нажмите `F12`, чтобы начать распознавание речи.

## Вариант 2. Продвинутая установка (Исходный код)

Используйте этот вариант, если вы хотите модифицировать код или пересобрать `.exe` файл самостоятельно.

### Требования
* ОС: Windows 10/11
* Python 3.10 или новее

### Шаг 1: Установка зависимостей
Склонируйте репозиторий и установите библиотеки:

```bat
python -m venv venv
call venv\Scripts\activate
pip install -r requirements.txt
```

### Шаг 2: Настройка окружения
Скопируйте пример конфига:
```bat
copy .env.example .env
```
Отредактируйте `.env`, вставив ваш `LLM_API_KEY`.

### Шаг 3: Запуск из исходников
Для запуска через Python используйте:
```bat
python launcher.py
```
Либо просто запустите `start.bat`.

### Шаг 4: Сборка своего EXE
Если вы внесли изменения в код и хотите собрать новый независимый `Shockwave.exe`, запустите:
```bat
build.bat
```
Скрипт автоматически установит `PyInstaller`, добавит все необходимые скрытые импорты и метаданные, а затем скомпилирует проект. Готовый файл появится в папке `dist`.

## Использование программы

* **F12 (удержание или нажатие)** — начать/завершить запись.
* Плавающий виджет покажет текущий статус:
  * `what is your command?` — ожидание.
  * `record` — идет запись с микрофона.
  * `processing` — распознавание речи (STT).
  * `normalization` — исправление пунктуации через LLM.
  * `ready` — текст скопирован в буфер обмена.
* Галочка на виджете позволяет на лету включать или отключать ИИ-нормализацию текста. При выключенной галочке распознанный текст копируется как есть, без задержек на запросы к LLM.
* Для закрытия программы используйте красный крестик (✖) на виджете.
