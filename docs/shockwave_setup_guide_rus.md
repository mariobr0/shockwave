# Shockwave — Руководство по установке и использованию

### 1. Требования
* Windows 10 / 11
* Python 3.10+

---

### 2. Установка и сборка
1. Склонируйте репозиторий или скачайте архив с кодом:
   ```bat
   git clone https://github.com/mariobr0/shockwave.git
   cd shockwave
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bat
   python -m venv venv
   call venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Соберите исполняемый файл:
   ```bat
   build.bat
   ```
   Скрипт скомпилирует `dist\Shockwave.exe` и создаст ярлык `Shockwave.lnk` в корне проекта.

*(Примечание: если вы не хотите компилировать `.exe`, программу можно запускать напрямую через Python двойным кликом по файлу **`start.bat`**).*

---

### 3. Первый запуск и настройка
1. Запустите `Shockwave.lnk` (или `start.bat`).
2. В появившейся панели управления:
   * **Пункт 2 (`Настроить API-ключ и LLM`):** Введите ваш API-ключ для нормализации текста.
   * **Пункт 3 (`Выбрать движок распознавания`):** Выберите `Whisper` (для кода и смешанной речи) или `GigaAM` (для русской речи).
   * **Пункт 4 (`Скачать/Проверить модели`):** Скачайте веса выбранной модели в локальную папку `models/`.
   * **Пункт 5 (`Change language to English`):** При необходимости переключите язык интерфейса на английский.

**Ручная настройка через `.env.example` (опционально):**  
Все параметры можно настроить вручную. Для этого скопируйте или переименуйте файл-шаблон `.env.example` в `.env`:
```bat
copy .env.example .env
```
и отредактируйте параметры (например, смените горячую клавишу `HOTKEY=f12`, позицию виджета или адрес локального сервера LLM) в любом текстовом редакторе.

---

### 4. Использование
1. В меню выберите **`1. Запустить Shockwave`** — в углу экрана появится плавающий виджет.
2. Нажмите горячую клавишу **`F12`** в любом приложении и надиктуйте фразу.
3. Нажмите **`F12`** повторно для завершения записи.
4. Дождитесь статуса **`ready`** и звукового сигнала — готовый текст с расставленной пунктуацией уже скопирован в буфер обмена (`Ctrl + V`).

---

### 5. Управление виджетом
* **Чекбокс `LLM norm`:** Включение/выключение нормализации текста через нейросеть.
* **Чекбокс `alert`:** Включение/выключение звукового сигнала по завершении распознавания.
* **Кнопка `×`:** Закрытие программы.
