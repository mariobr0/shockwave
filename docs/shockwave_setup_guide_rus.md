# Shockwave (v0.9.0) — Руководство по настройке

## Вариант 1. Простой запуск (Готовый .EXE)

Это самый быстрый способ запустить Shockwave без необходимости настраивать виртуальное окружение Python вручную.

### Шаг 1: Запуск
1. Запустите `Shockwave.lnk` (ярлык в корне проекта) или `dist\Shockwave.exe`.
2. При первом запуске откроется **Панель управления (Launcher)** в консоли.

### Шаг 2: Настройка API-ключа и LLM
В открывшейся панели управления выберите пункт **`2. Настроить API-ключ и LLM`**:
* Введите ваш API-ключ (например, ключ Gemini).
* Выберите или оставьте по умолчанию модель `gemini-2.5-flash-lite`.
* Настройки автоматически сохранятся в локальный файл `.env`.

### Шаг 3: Выбор и загрузка моделей (STT)
1. В пункте **`3. Выбрать движок распознавания (STT)`** выберите:
   * **Whisper** — для смешанной речи, английских слов и кода.
   * **GigaAM** — для молниеносной русской речи.
2. В пункте **`4. Скачать/Проверить модели распознавания`** программа проверит наличие модели. При первом старте вы сможете скачать нужные модели прямо в локальную папку `models/`.

### Шаг 4: Работа с приложением
1. Выберите пункт **`1. Запустить Shockwave`**.
2. В углу экрана появится аккуратный виджет со статусом `what is your command?`.
3. Нажмите горячую клавишу **`F12`** в любом приложении Windows и надиктуйте фразу.
4. Нажмите **`F12`** повторно для завершения записи.
5. При появлении статуса **`ready`** (и звукового сигнала) текст автоматически скопирован в буфер обмена — просто нажмите **`Ctrl + V`**!

## Вариант 2. Запуск из исходного кода для разработчиков

Используйте этот вариант, если вы хотите модифицировать код или собрать свой кастомный бинарник.

### Требования
* ОС: Windows 10 / 11
* Python 3.10 или новее

### Шаг 1: Установка зависимостей
Склонируйте репозиторий и создайте виртуальное окружение:

```bat
python -m venv venv
call venv\Scripts\activate
pip install -r requirements.txt
```

### Шаг 2: Файл конфигурации (.env)
Скопируйте шаблон:
```bat
copy .env.example .env
```
Укажите ваш API-ключ в `.env` или настройте его через интерактивный лаунчер.

### Шаг 3: Запуск в режиме разработки
```bat
python src/launcher.py
```
*(Или запустите скрипт `start.bat`)*.

### Шаг 4: Сборка в один файл (.EXE)
Чтобы пересобрать проект в независимый исполняемый файл:
```bat
build.bat
```
Скрипт автоматически упакует проект с иконкой, звуковыми ресурсами и зависимостями в `dist/Shockwave.exe`, а также создаст готовый ярлык `Shockwave.lnk` в корне проекта.
